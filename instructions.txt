Improved Prompt for Building a Job Portal Dashboard
🎯 Project Overview
Develop a production-ready MERN stack job portal for finance and automobile companies, enabling seamless interaction between recruiters and applicants. The portal must include role-based dashboards (Applicant, Recruiter, Admin), an AI-powered resume builder, and advanced job management features. The frontend should use a template from the @/Dashboard/free-react-tailwind-admin-dashboard-main folder, ensuring all functionalities match the template's standards. Focus exclusively on the frontend for this phase, commenting out or removing backend-related code while ensuring compatibility with MongoDB, Node.js, and Express.js for future integration.
📦 Core Tech Stack

Frontend: React.js, Tailwind CSS, Tailwind UI, Framer Motion (for animations), Recharts (for analytics)
Styling: SCSS for custom designs (cards, pages, tabs)
Future Backend: Node.js, Express.js, MongoDB (Mongoose), JWT + OAuth (Google, Microsoft, Apple)
File Storage: Cloud storage (GridFS/S3) for resumes (to be implemented later)

🔐 Authentication (Frontend Considerations)

Simulate JWT-based authentication with role-based access (Applicant, Recruiter, Admin) for dashboard navigation.
Mock social login UI for Google, Microsoft, and Apple (fetch name, email, avatar placeholders).
Remove or comment out backend authentication logic to focus on frontend functionality.
Ensure dashboards are accessible without authentication for testing purposes.

👥 Dashboard Requirements
Build three dashboards (Applicant, Recruiter, Admin) using the provided Tailwind UI-based template from @/Dashboard/free-react-tailwind-admin-dashboard-main. Ensure all dashboards are:

Responsive: Mobile-first, compatible with all devices (desktop, tablet, mobile).
Themed: Support light and dark modes with system-dependent toggling, adjusting font colors for readability (e.g., dark fonts on light theme, light fonts on dark theme).
Animated: Use Framer Motion for smooth transitions, hover effects, and floating card animations with light shadows.
Modular: Divide code into independent components (cards, pages, tabs) in separate folders for maintainability.
Styled: Use SCSS for custom card designs with unique gradients and hover animations (simple yet attractive).
Multilingual: Support Indian languages (e.g., Hindi, Tamil) with a language switcher.
Font Customization: Allow font size and family changes via settings.
Error Handling: Include Tailwind-designed 404 and 500 error pages.

Browse Jobs: Search jobs with filters (location, salary, experience, type, industry).

Analytics: Display application stats and interview schedules (meetings/assessments) in cards and tables.
