Work Experience:
  Database Field          → Display Logic
  ─────────────────────────────────────────────────────────────
  jobTitle                → jobTitle || title || 'Position Not Specified'
  companyName             → companyName || company || 'Company Not Specified'
  startDate               → new Date(startDate).toLocaleDateString()
  endDate                 → isCurrentJob ? 'Present' : new Date(endDate).toLocaleDateString()
  isCurrentJob            → isCurrentJob || isCurrentRole
  description             → description (with null check)
  achievements            → achievements.map() (with null check)

Education:
  Database Field          → Display Logic
  ─────────────────────────────────────────────────────────────
  degree                  → degree || 'Degree Not Specified'
  institution             → institution || 'Institution Not Specified'
  fieldOfStudy            → fieldOfStudy (displayed if present)
  startDate               → new Date(startDate).getFullYear()
  endDate                 → isCurrentlyStudying ? 'Present' : new Date(endDate).getFullYear()
  grade                   → grade (displayed if present)
  isCurrentlyStudying     → Shows "Present" instead of end year
