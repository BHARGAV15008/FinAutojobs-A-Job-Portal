===============================================
CROSS-DEVICE ACCESS SETUP GUIDE
===============================================

This guide will help you access FinAutoJobs from other devices on the same network (e.g., mobile phone, tablet, another computer).

PREREQUISITES:
- All devices must be connected to the same WiFi network
- Firewall must allow connections on ports 3000 and 5000

===============================================
STEP 1: FIND YOUR COMPUTER'S LOCAL IP ADDRESS
===============================================

Windows:
1. Open Command Prompt (CMD)
2. Type: ipconfig
3. Look for "IPv4 Address" under your active network adapter
   Example: 192.168.1.100

Mac:
1. Open Terminal
2. Type: ifconfig
3. Look for "inet" address under en0 or en1
   Example: 192.168.1.100

Linux:
1. Open Terminal
2. Type: ip addr show
3. Look for "inet" address
   Example: 192.168.1.100

===============================================
STEP 2: UPDATE BACKEND CONFIGURATION
===============================================

1. Navigate to: backend/.env
   (If it doesn't exist, copy from backend/.env.example)

2. Update these lines:
   FRONTEND_URL=http://YOUR_LOCAL_IP:3000
   CORS_ORIGIN=http://YOUR_LOCAL_IP:3000,http://localhost:3000

   Example:
   FRONTEND_URL=http://192.168.1.100:3000
   CORS_ORIGIN=http://192.168.1.100:3000,http://localhost:3000

3. Save the file

===============================================
STEP 3: UPDATE FRONTEND CONFIGURATION
===============================================

1. Navigate to: frontend/.env.local
   (If it doesn't exist, copy from frontend/.env.example)

2. Update this line:
   VITE_API_URL=http://YOUR_LOCAL_IP:5000/api

   Example:
   VITE_API_URL=http://192.168.1.100:5000/api

3. Save the file

===============================================
STEP 4: RESTART SERVERS
===============================================

1. Stop both servers (Ctrl+C in each terminal)

2. Start Backend:
   cd backend
   npm run dev

3. Start Frontend (in a new terminal):
   cd frontend
   npm run dev

4. Wait for both servers to start successfully

===============================================
STEP 5: ACCESS FROM OTHER DEVICES
===============================================

On your mobile phone, tablet, or another computer:

1. Make sure the device is connected to the SAME WiFi network

2. Open a web browser

3. Go to: http://YOUR_LOCAL_IP:3000
   Example: http://192.168.1.100:3000

4. You should see the FinAutoJobs login page!

===============================================
TROUBLESHOOTING
===============================================

Problem: Cannot access from other devices

Solution 1: Check Firewall
- Windows: Allow ports 3000 and 5000 in Windows Firewall
- Mac: System Preferences → Security & Privacy → Firewall → Firewall Options
- Linux: sudo ufw allow 3000 && sudo ufw allow 5000

Solution 2: Verify IP Address
- Make sure you're using the correct local IP
- IP should start with 192.168.x.x or 10.0.x.x
- Do NOT use 127.0.0.1 or localhost

Solution 3: Check Network
- Ensure all devices are on the same WiFi network
- Some networks have "AP Isolation" enabled which blocks device-to-device communication
- Try using a different WiFi network or create a mobile hotspot

Solution 4: Restart Everything
- Restart both backend and frontend servers
- Clear browser cache on the device
- Try accessing in incognito/private mode

Solution 5: Check Server Logs
- Look for CORS errors in backend console
- Check if servers are binding to 0.0.0.0 (not just localhost)

===============================================
VERIFICATION
===============================================

Your setup is correct if you see:

Backend Console:
✅ Server running on http://0.0.0.0:5000
✅ Local: http://localhost:5000
✅ Network: http://192.168.1.100:5000

Frontend Console:
✅ Local: http://localhost:3000
✅ Network: http://192.168.1.100:3000
